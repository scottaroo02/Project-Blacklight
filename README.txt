PROJECT BLACKLIGHT - HANDSPRING VISOR DELUXE BUILD

This package contains the Palm OS C source and a GitHub Actions workflow that builds Blacklight.prc with prc-tools-remix and the official archived Palm OS SDK 3.1.

To use:
1. Create a new GitHub repository.
2. Upload the contents of this folder, including the hidden .github folder.
3. Open Actions > Build Blacklight PRC > Run workflow.
4. When complete, download the artifact named Blacklight-Visor-Deluxe-PRC.
5. Inside is Blacklight.prc for HotSync/install to the Visor Deluxe.
